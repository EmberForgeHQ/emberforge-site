Meet the Creator

Hi, I’m Katie.

I built EmberForge after spending years on the other side of community tools: running the community, solving the problems, and discovering exactly how quickly “this should be simple” can become an entire evening, a bot, a database, and somehow its own roadmap.

Founder / Builder / Community person
Community first.
Tools second.

EmberForge grew from practical problems, late-night tinkering, and a recurring suspicion that if a tool kept fighting the people using it, I could probably build something that fit better.

Where it started

Before EmberForge, there was PCR.

Phoenix Clan Rising is where the problems showed up first. EmberForge is where I started turning those problems into tools.

EmberForge did not begin as a software company. It started inside Phoenix Clan Rising, the gaming community I was already running.

Like most community owners, I kept running into little problems that existing tools either did not solve, solved awkwardly, or wanted me to reshape my whole workflow around.

So I started creating bots for myself.

At first they were practical tools for PCR: moderation, economy features, community systems, staff coordination, automation, and the odd little jobs that appear when a community grows enough moving parts.

“Wait... could I just build this?”

That question kept coming back. One bot became another. Individual tools started becoming systems. Systems started becoming something I could refine, reuse, and make better.

Eventually, one of those projects became Ember Vault. What started as a private community economy grew into its own product with its own codebase, database, service identity, infrastructure, multi-guild boundaries, and public roadmap.

That was the moment the idea started stretching beyond my own community. I realized the tools I was building because I needed them might be useful to other community owners too.

Then the same thing happened again. A crosschat problem turned into Ember Nexus, a much bigger idea for connecting game servers, Discord, websites, shops, identities, and automation without hardcoding one community's setup into the center of everything.

At that point, EmberForge stopped being the name of one project and became the workshop around all of them.

The path here

A community became a workshop.

01 / PCR

Run the community.

Real players, real staff, real workflows, real edge cases. The kind of environment where “simple” features learn humility.

02 / BUILD

Make what was missing.

Bots started as internal tools built for the things PCR actually needed, not hypothetical feature lists. Vault proved some of those systems could stand on their own.

03 / EMBERFORGE

Build beyond one community.

EmberForge became the workshop for turning those lessons into products, documenting the decisions behind them, and keeping room for the next useful thing.

How I build

Founder fingerprints, not founder wallpaper.

EmberForge carries my curiosity, practicality, community experience, and occasional refusal to accept that a clumsy workflow is “just how it works.” The founder fingerprints stay visible, but the systems themselves are being built to survive beyond one person, one Discord server, or one community.

Start with the person doing the work.

Community owners, moderators, admins, event teams, and staff are usually juggling more than the software realizes. The tool should respect that.

Build from reality.

If a feature looks perfect on paper but becomes annoying in daily use, reality wins. We change the feature.

Keep it human.

Software can be professional without sounding like it was assembled by a committee inside a spreadsheet.

Leave room to grow.

Today's useful tool should not become tomorrow's trap. EmberForge is built to be refined as the problems get bigger.

What came next

Apparently, an actual product family.

Ember Vault is in active development and preparing for public beta. Ember Nexus is deliberately still on the workbench. EmberForge HQ is now open for the people who want to follow the work, test things, ask questions, and inevitably uncover the weird edge case we did not know existed yet.
